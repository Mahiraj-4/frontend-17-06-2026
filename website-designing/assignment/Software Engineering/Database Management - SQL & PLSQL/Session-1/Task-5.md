# Task 5: Database Comparison

## MySQL

**Use Case:**
Web applications, CMS platforms (WordPress, Drupal), aur e-commerce sites.

**Features:**
Ye ek fast, open-source RDBMS hai jo high-speed read operations ke liye best mana jata hai. Meta (Facebook), Twitter, aur YouTube jaisi companies ise bade paimane par use karti hain.

---

## PostgreSQL

**Use Case:**
Complex web systems, financial applications (Fintech), aur data analytics backends.

**Features:**
Ye ek advanced open-source object-relational database hai. Ye strict SQL standards, complex calculations, JSON data type, aur geographical data (GIS) ko behtareen handle karta hai.

---

## Oracle Database

**Use Case:**
Large enterprise systems, banking/finance, ERP/CRM platforms, aur airlines booking systems.

**Features:**
Ye enterprise-grade paid database software hai jo heavy workloads, massive transaction volume, high security, aur 24/7 reliability ke liye industry standard hai.

---

## SQLite

**Use Case:**
Mobile apps (Android & iOS), desktop software, IoT devices, aur browser caching.

**Features:**
Ye ek lightweight, serverless aur zero-configuration database hai. Iska poora data ek single file me store hota hai, isliye ise alag se server setup kiye bina app ke andar hi embed kiya jata hai.

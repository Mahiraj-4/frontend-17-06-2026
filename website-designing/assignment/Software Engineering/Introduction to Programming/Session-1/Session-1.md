## Task 1: Define a Program

A **program** is a set of instructions written in a programming language that tells a computer or mobile device what to do. Programs are used to perform specific tasks such as displaying information, calculating values, sending messages, or processing payments. For example, when I use **Zomato** to order food, the app uses programs to show restaurants, display menus, add food items to the cart, calculate the total price, process the payment, and track the order.

## Task 2: Popular Programming Languages

| Programming Language | Usually Compiled / Interpreted / Both | Description                                                                                                                                   |
| -------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Java**             | Compiled and Interpreted              | Java source code is compiled into bytecode, which is then executed by the Java Virtual Machine (JVM).                                         |
| **Python**           | Interpreted                           | Python code is generally executed by the Python interpreter, although Python implementations also perform compilation to bytecode internally. |
| **JavaScript**       | Both                                  | JavaScript is executed by JavaScript engines, which commonly use interpretation along with Just-In-Time (JIT) compilation.                    |

### Summary

* **Java:** Both compiled and interpreted
* **Python:** Usually interpreted
* **JavaScript:** Both compiled and interpreted

## Task 3: Flowchart for Booking a Movie Ticket on BookMyShow

### Flowchart Steps

The flowchart for booking a movie ticket on BookMyShow follows these steps:

1. **Start**
2. Open the BookMyShow app.
3. Select the city/location.
4. Select the movie.
5. Select the date.
6. Select the preferred theatre.
7. Select the show time.
8. Select the number of seats.
9. Select available seats.
10. Click on **Proceed/Continue**.
11. Check the booking details and total amount.
12. Select a payment method.
13. Complete the payment.
14. **Is payment successful?**

    * **Yes:** Booking is confirmed.
    * **No:** Try the payment again or select another payment method.
15. Receive the booking confirmation/ticket.
16. **End**

## Task 4: Algorithm for Ordering Food on Swiggy

### Algorithm: Ordering Food Online

**Step 1:** Start.

**Step 2:** Open the Swiggy app on the mobile phone.

**Step 3:** Log in to the account or create an account if required.

**Step 4:** Enter or confirm the delivery address.

**Step 5:** Search for a restaurant or browse the available restaurants.

**Step 6:** Select a restaurant.

**Step 7:** View the restaurant's menu.

**Step 8:** Select the required food items.

**Step 9:** Add the selected food items to the cart.

**Step 10:** Open the cart and check the selected items and quantities.

**Step 11:** Check the total amount, including delivery charges and other applicable charges.

**Step 12:** Confirm the delivery address and order details.

**Step 13:** Select a payment method such as UPI, card, wallet, or other available options.

**Step 14:** Make the payment.

**Step 15:** Check whether the payment was successful.

**Step 16:** If the payment is successful, place and confirm the order.

**Step 17:** Receive the order confirmation.

**Step 18:** Track the food delivery until it arrives.

**Step 19:** Receive the food and complete the order.

**Step 20:** End.

# Conclusion

Programming is the process of creating instructions that computers can understand and execute. Programs help us perform many everyday activities, such as ordering food, booking movie tickets, making payments, and using social media applications. Algorithms provide step-by-step solutions to problems, while flowcharts represent these steps visually. Compilers and interpreters help convert or execute programming language instructions so that computers can perform the required tasks.

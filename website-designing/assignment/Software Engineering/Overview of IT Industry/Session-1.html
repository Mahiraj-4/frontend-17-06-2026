Qs. 1:- Name 5 IT job roles and write one line about what each role does.

1) Software Developer: Designs, writes, tests, and maintains the computer code that builds software applications and programs to meet specific user or business needs.

2) Information Security Analyst: Plans and implements security measures to protect an organization's computer networks, systems, and sensitive data from cyberattacks.

3) Network Administrator: Manages and maintains an organization’s computer networks, ensuring that systems are secure, hardware is configured properly, and connectivity is maintained.

4) Database Administrator: Organizes, manages, and secures data within an organization's systems, monitoring database performance and controlling user access permissions.

5) IT Support Specialist: Serves as the primary point of contact to assist users with technical issues, troubleshooting hardware, software, and network connectivity problems.

Global International Hub for User Binaries: (A widely accepted retronym for a Git-based code repository). It is used to store, track, and collaborate on software code projects.

=> SLACK

Searchable Log of All Conversation and Knowledge. Used as an instant messaging and collaboration platform for teams to communicate and share files.

=> JIRA

Derived from the Japanese word Gojira (Godzilla). Used for project management and issue tracking during software development.

=> IDE

Integrated Development Environment. Used by programmers as an all-in-one software application to write, edit, test, and debug code.

=>API

Application Programming Interface. Used as a bridge to allow two different software systems or applications to communicate with each other.



Qu. 4:- Name any 5 programming languages and mention one popular use case for each.

1) PYTHON

Artificial Intelligence and Machine Learning. Python is the industry standard for AI due to its simple syntax and powerful libraries like TensorFlow and PyTorch.

2) JAVASCRIPT

Web Development (Frontend). It is the core language powering the internet, allowing developers to create interactive elements like animations, pop-up menus, and dynamic web content.

3) JAVA

Enterprise Software and Backend Systems. Known for its "write once, run anywhere" philosophy, it is widely used by large corporations to build highly scalable, secure, and heavy-duty banking and business applications.

4) C++

Video Game Development. It provides low-level control over hardware and memory, making it the ideal choice for building performance-critical high-end game engines like Unreal Engine.

5) SWIFT

iOS Mobile Applications. Developed by Apple, it is the exclusive, modern language used to build native apps for iPhones, iPads, and Apple Watches.



Qu. 5:- What is the difference between a developer and a tester? Answer in 2 lines.

A developer is responsible for writing the code and building software applications to meet specific requirements.

A tester evaluates that software to identify bugs, ensuring it works correctly and meets quality standards before release.
